1️⃣  Activar el ambiente virtual:
    $ source venv/bin/activate

2️⃣  Verificar que todo funciona:
    $ python generar_podcast.py

3️⃣  Initializar Git (si aún no lo has hecho):
    $ bash init-git.sh

4️⃣  En GitHub crear nuevo repositorio y:
    $ git remote add origin https://github.com/tu-usuario/clonvoz.git
    $ git branch -M main
    $ git push -u origin main
